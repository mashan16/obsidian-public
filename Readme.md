# Архитектура и сборка сайта

Сайт представляет собой автоматическую публикацию публичной части хранилища Obsidian.
## Технологический стек
* **Источник контента:** Obsidian (Markdown-заметки)
* **Генератор сайта:** Quartz (генератор статических сайтов)
* **Хостинг и CI/CD:** GitHub Pages + GitHub Actions
## Как это работает
1. Изменения из Obsidian пушатся в основной репозиторий на GitHub.
2. GitHub Actions автоматически запускает сборку Quartz.
3. Quartz обрабатывает заметки, фильтрует приватный контент и генерирует статический HTML.
4. Готовый результат публикуется и отображается на GitHub Pages.
