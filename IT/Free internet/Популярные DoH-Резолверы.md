Популярные альтернативные публичные DoH-сервисы

| **Сервис**        | **Особенности / Профиль**                                        | **URL для DoH (HTTPS)**                            | **Hostname для DoT / Android**    |
| ----------------- | ---------------------------------------------------------------- | -------------------------------------------------- | --------------------------------- |
| **Quad9**         | Швейцария, упор на безопасность и фильтрацию вредоносных сайтов. | https://dns.quad9.net/dns-query                    | `dns.quad9.net`                   |
| **AdGuard DNS**   | Блокировка рекламы и трекеров "из коробки".                      | https://dns.adguard-dns.com/dns-query              | `dns.adguard-dns.com`             |
| **Control D**     | Высокая гибкость, бесплатные варианты без логов.                 | https://freedns.controld.com/p0                    | `p0.freedns.controld.com`         |
| **NextDNS**       | Публичный стандартный резолвер (без регистрации).                | https://dns.nextdns.io                             | `dns.nextdns.io`                  |
| **Mullvad DNS**   | Строгая приватность, шведский сервиc.                            | https://dns.mullvad.net/dns-query                  | `dns.mullvad.net`                 |
| **DNS.SB**        | Немецкий провайдер, полная нейтральность, без фильтров и логов.  | https://doh.dns.sb/dns-query                       | `dot.dns.sb`                      |
| **FDN**           | Французский некоммерческий провайдер                             | https://ns0.fdn.fr/dns-query                       | ns0.fdn.fr                        |
| **CleanBrowsing** | Фильтрация нежелательного контента                               | https://doh.cleanbrowsing.org/doh/security-filter/ | security-filter.cleanbrowsing.org |
