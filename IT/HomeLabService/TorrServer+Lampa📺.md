Смотрим фильмы через торрент удобно на Windows или ТВ
## Используемые приложения
### Jackett
Это бесплатный и open-source проект, который можно описать как *универсальный "мост" между торрент-клиентами и торрент-трекерами*. Его ключевая функция заключается в том, чтобы предоставить пользователю возможность искать контент сразу по множеству трекеров, экономя время и нервы.
### TorrServer Matrix
 Позволяет  смотреть видео из торрентов в реальном времени без скачивания файла целиком.
>Программа для загрузки торрентов по HTTP протоколу.  
Подключение к торренту идет локально. **Если ваш провайдер блокирует торренты — будьте осторожны.**  
Кэш по умолчанию хранится в оперативной памяти, поэтому не портится внутренняя флеш-память устройства.  
Программа состоит из двух частей: клиент и сервер. Сервер может быть как локальным, так и располагаться в Интернете.  
После первого запуска заходим в «Боковое меню» → «Обновление» → «Установить / Обновить сервер» для загрузки сервера из сети.
Она работает как торрент-клиент, который передает контент по HTTP-протоколу, а не сохраняет его. 
Через него мы и будем стримить видеопоток в **Lampa** 
### Lampa
 Через неё мы и будем искать и смотреть фильмы на ТВ ПК или Смартфоне с Android

## Логика работы 
1. Запускаем **TorrServer Matrix**
2. Открываем **Lampa** ищем фильм, выбираем нужный по озвучке и качеству торррент
3. **Lampa** С помощью парсера **Jackett** ищем его на торрент трекерах и отправляет его на **TorrServer Matrix**
4. Выбранный торрент начинает скачиваться  в **TorrServer Matrix** И транслировать видеопоток обратно в **Lampa** в **VLC плеер**

## Краткое описание инструкции:
1.  Скачать и запустить TorrServer **TorrServer**  на Windows, Linux или Android смартфоне (Ссылки на скачивания будут ниже)
2. Настроить  **Lampa** по инструкции ниже
3. Установить **VLC** Плеер для [WIndows](https://images.videolan.org/index.ru.html) с офф сайта,  или магазина приложений на [Android](https://play.google.com/store/apps/details?id=org.videolan.vlc) 
# TorrServer
## Windows
### Шаг 1, Устанавливаем или запускаем Portable врсию.
Выбирайте уже сами, нужно ли вам еще одно приложение висящее в фоне или вы сторонник Portable версий
#### Установка
Что-бы постоянно не запуска вручную можно просто установить его на свой ПК
1. Скачиваем **TorrServer_Setup.exe** с [GitHub/Noperkot](https://github.com/Noperkot/TorrServerInstaller/releases) запускаем, устанавливаем
2. Готово, наш TorrServer Matrix запущен по адресу http://localhost:8090
- Или в трее ![[image-2025.11.14 📺 TorrServer+Lampa-6.png]]
   
#### Запуск  portable версии 
1. Переходим на страницу проекта на GitHub [YouROK/TorrServer](https://github.com/YouROK/TorrServer/releases) 
2. Кликаем на `Show all 22 assets`  чтобы открыть весь список
3. Находим  `TorrServer-windows-amd64.exe` скачиваем, запускаем
4. Появляется cmd окно с логом запуска приложения TorrServer
5. Готово, наш TorrServer Matrix запущен по адресу http://127.0.0.1:8090
### Шаг 2, Узнаём IP адрес ПК
==Не актуально если Lampa запускается на этом же ПК что и Torserver
В таком случае адрес будет 127.0.0.1:8090==
1. Открываем Powershell или CMD
2. Вводим команду `ipconfig` клацаем Enter
3. ![[image-2025.11.14 📺 TorrServer+Lampa-7.png]]
4. В моём случае адрес `172.10.10.117`, записываем его или запоминаем, его нужно будет указать в Lampa в разделе адрес TorrServer

## Настройка Lampa
### Смарт ТВ
В процессе написания
### Windows
1. Настройки > Остальное > Тип клавиатуры изменить на `Системная`
2. Настройки > TorrServer > указываем IP адрес  и порт нашего TorrServer  если Lampa и Torrserver запускаются на одном ПК то адрес нужно указать `127.0.0.1:8090`
3. Настройки > Парсер > Типа парсера должен быть `Jackreet`
4. Настройки > Парсер > ссылка указываете` jacred.xyz`
5. Настройки > Плеер > Тип плеера для торрентов `указываем внешний`
6. Настройки > Плеер > Путь к плееру VLC уже прописан (`C:/Program Files/VideoLAN/VLC/vlc.exe`)
- Если установили PotPlayer то указываем путь к его .exe посмотреть можно в ярлыке плеера)
- На Windows у меня почему то не отображались постеры фильмы (превью фильмов) помогло следующее:
  >Настройки > Остальное > использовать протокол https  `выключаем `
