## Запуск PS скриптов из github

```
Напиши PowerShell скрипт который корректно работает в двух режимах:
1. Запуск из файла через ПКМ → "Выполнить с помощью PowerShell"
2. Запуск через irm "https://..." | iex

Требования:
- Если нет прав админа — запросить UAC и перезапустить с правами
- При запуске из файла — перезапускать через -File "$PSCommandPath"
- При запуске через iex — перезапускать через -Command с Invoke-RestMethod по URL
- После выполнения окно не должно закрываться (Read-Host "Press Enter to exit")
- При запуске из файла Read-Host в конце скрипта
- При запуске через iex Read-Host передать в -Command после точки с запятой
- Определять режим запуска через $PSCommandPath (пустой = iex, не пустой = файл)
```
