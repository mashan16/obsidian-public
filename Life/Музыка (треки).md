## Промт для ИИ

```
У меня есть список треков из YouTube Music (понравившаяся музыка). Вот данные в формате `Исполнитель — Трек [Альбом]` (каждый трек на новой строке). Сделай из этого чистую MD-таблицу с двумя столбцами: Исполнитель и Трек. Правила чистки:

- Убрать `[]` в конце (пустой альбом)
- Убрать дубли треков
- Убрать хэштеги (`#слово`) из названий, но сохранить `#число` если это часть названия
- Убрать префикс исполнителя из названия трека если он там дублируется (`Fun Mode — Fun Mode — Название` → `Fun Mode — Название`)
- Убрать суффикс `(ПАРОДИЯ Исполнитель)` из названий
- Убрать `(Official Music Video)` / `(Official Video)` из названий
- Убрать эмодзи и подписи типа "Авторская песня" из названий
```

## Скрипт для браузера youtube music

**Стабильный скрипт для браузера** — открой [music.youtube.com/playlist?list=LM](https://music.youtube.com/playlist?list=LM), дождись полной загрузки страницы, вставь в консоль (F12):
Скрипт ждёт 5 одинаковых результатов подряд перед остановкой — не прервётся раньше времени.

```javascript
(async function () {
  console.log("Загружаем треки...");
  const PAUSE = 3000;
  const MAX = 800;
  let last = 0;
  let same = 0;

  for (let i = 0; i < MAX; i++) {
    window.scrollTo(0, document.body.scrollHeight);
    await new Promise(r => setTimeout(r, PAUSE));
    const n = document.querySelectorAll("ytmusic-responsive-list-item-renderer").length;
    if (n === last) {
      if (++same >= 5) { console.log(`✅ Загружено ${n} треков`); break; }
    } else { same = 0; }
    last = n;
    console.log(`📜 ${n} треков...`);
  }

  const songs = Array.from(
    document.querySelectorAll("ytmusic-responsive-list-item-renderer")
  ).map(el => {
    const cols = el.querySelectorAll(".secondary-flex-columns yt-formatted-string");
    const artist = cols[0]?.textContent?.trim() || "";
    const title = el.querySelector(".title")?.textContent?.trim() || "";
    const album = cols[1]?.textContent?.trim() || "";
    return `${artist} — ${title} [${album}]`;
  }).filter(s => s !== " —  []");

  const result = songs.join("\n");
  console.log("\n===== СПИСОК ТРЕКОВ =====\n" + result);
  navigator.clipboard.writeText(result)
    .then(() => console.log(`✅ Скопировано ${songs.length} треков!`))
    .catch(() => console.log("⚠️ Скопируй вручную из консоли"));
})();
```
